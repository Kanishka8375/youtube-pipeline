# Weekly Production Checklist

Copy this page once per week into the Weekly Reviews database, or keep it as a Notion
template button called **New Weekly Checklist**.

Written for **Tier 1** (1 long-form + 2–3 Shorts). For Tier 2, run Tuesday–Thursday
twice — see `02-weekly-time-system.md`.

---

## Weekly objective

- [ ] Publish 1 long-form video
- [ ] Publish 2–3 Shorts
- [ ] Review analytics
- [ ] Update next week's topic queue
- [ ] Track affiliate opportunities

---

## Monday — Planning and topic selection

**Goal:** choose one topic strong enough to carry one long-form video and 2–3 Shorts.

- [ ] Open last week's analytics
- [ ] Review top-performing video/topic patterns
- [ ] Review comments for audience requests
- [ ] Check 3–5 competing channels for topic ideas
- [ ] Scan current AI tool / product updates
- [ ] Choose 1 long-form topic
- [ ] Confirm target audience (creators / freelancers)
- [ ] Define primary goal (traffic / trust / monetization)
- [ ] Define affiliate fit
- [ ] Write working title
- [ ] Create rough outline
- [ ] Add video card to the Video Pipeline
- [ ] Set publish date
- [ ] List 2–3 possible Shorts angles

**Output:** topic chosen, outline created, pipeline card updated, Shorts angles listed.

---

## Tuesday — Script writing

**Goal:** a tight script for a 6–9 minute video.

- [ ] Write hook
- [ ] Write intro promise
- [ ] Write main sections
- [ ] Add tool examples / comparisons / workflow steps
- [ ] Add a downside or nuance for credibility
- [ ] Write verdict / recommendation
- [ ] Write CTA
- [ ] Mark visual notes in the script
- [ ] Check length against the 6–9 minute target
- [ ] Save the final script on the pipeline card

### Script QA

- [ ] Clear audience
- [ ] Clear result
- [ ] No fluff
- [ ] Real examples included
- [ ] Affiliate mention feels natural
- [ ] Strong first 30 seconds

**Output:** final script, visual note sheet.

---

## Wednesday — Voiceover and screen capture

**Goal:** record everything editing will need, so Thursday never blocks on a missing shot.

- [ ] Record voiceover
- [ ] Remove major mistakes / breaths
- [ ] Record screen demos for every featured tool
- [ ] Capture UI close-ups
- [ ] Capture pricing / features screens if relevant
- [ ] Save screenshots and logos
- [ ] Gather support visuals
- [ ] Organize files into the project folder
- [ ] Set pipeline status to **Recorded**

**Output:** voiceover finished, screen recordings complete, assets organized.

---

## Thursday — Edit long-form video

**Goal:** complete the main edit in one sitting.

- [ ] Import script, audio and visuals
- [ ] Build rough cut
- [ ] Remove dead space
- [ ] Add screen recordings
- [ ] Add text overlays
- [ ] Add callouts / highlights
- [ ] Add light music / SFX
- [ ] Review pacing
- [ ] Export draft
- [ ] Watch the export once, start to finish
- [ ] Export final version
- [ ] Set pipeline status to **Editing** or **Packaging**

### Edit QA

- [ ] Hook lands in the first 10 seconds
- [ ] No unnecessary intro
- [ ] Visual change every few seconds
- [ ] Text readable on mobile
- [ ] Audio clean
- [ ] Verdict is unambiguous

**Output:** long-form edited, final export saved.

---

## Friday — Shorts, thumbnail, title, upload setup

**Goal:** package the main video and repurpose it into Shorts.

### Shorts

- [ ] Identify 2–3 strong clips
- [ ] Cut Shorts
- [ ] Add captions
- [ ] Add hook text
- [ ] Export Shorts
- [ ] Create Shorts Queue entries

### Packaging

- [ ] Create thumbnail
- [ ] Draft 2–3 title options
- [ ] Choose final title
- [ ] Write description
- [ ] Add affiliate links
- [ ] Add affiliate disclosure
- [ ] Write pinned comment
- [ ] Add chapters
- [ ] Add to playlist
- [ ] Add end screen / cards
- [ ] Schedule long-form
- [ ] Schedule Shorts
- [ ] Create the Packaging Tracker row
- [ ] Set pipeline status to **Scheduled**

### Packaging QA

- [ ] Thumbnail readable at mobile size
- [ ] Title is specific, not clever
- [ ] Description includes links
- [ ] Pinned comment includes the CTA
- [ ] Affiliate links tested by actually clicking them

**Output:** main video scheduled, Shorts scheduled, packaging logged.

---

## Sunday — Analytics review and optimization

**Goal:** learn what worked and set up next week.

- [ ] Check CTR
- [ ] Check retention at 30 seconds
- [ ] Check average view duration
- [ ] Check top traffic source
- [ ] Check affiliate link clicks
- [ ] Read comments and questions
- [ ] Review Shorts viewed vs swiped
- [ ] Log metrics in the Weekly Reviews entry
- [ ] Confirm the auto-calculated weekly score looks right
- [ ] Note one thing to repeat
- [ ] Note one thing to improve
- [ ] Add next-video ideas to the Ideas Bank

**Output:** metrics logged, lesson captured, next week's direction decided.

---

## Affiliate disclosure

Put a disclosure in the description of any video containing affiliate links, and say it
out loud once in the video. In the US this is an FTC requirement, not a courtesy, and
YouTube also asks you to tick the paid-promotion box. Keep a fixed line in your
description template so it is never forgotten.
