# Weekly Time System

Two cadence tiers. Pick one, set the matching targets on the Weekly Reviews database,
and don't switch mid-quarter — the trend data is only comparable within a tier.

---

# Tier 1 — Sustainable (1 long-form + 2–3 Shorts)

**Total: 9h 45m/week.** Assumes template reuse and one focused operator.

## Monday — Planning · 1h 15m

| Block | Task |
|---|---|
| 0:00–0:20 | Review analytics: CTR, retention, affiliate clicks, comments |
| 0:20–0:40 | Competitor and trend scan: 3–5 channels, AI tool news, audience requests |
| 0:40–1:00 | Pick the topic: define audience, goal, affiliate angle |
| 1:00–1:15 | Create Notion entries: pipeline card, 2–3 Shorts ideas, publish date, rough outline |

## Tuesday — Scripting · 1h 30m

| Block | Task |
|---|---|
| 0:00–0:15 | Refine title and angle |
| 0:15–0:45 | Write full outline: hook, intro, 3–5 sections, verdict |
| 0:45–1:15 | Write the script draft |
| 1:15–1:30 | Tighten: cut fluff, add CTA, add visual notes |

## Wednesday — Recording · 1h 30m

| Block | Task |
|---|---|
| 0:00–0:20 | Set up and record voiceover |
| 0:20–0:35 | Light voiceover cleanup |
| 0:35–1:10 | Screen recordings: tools, comparisons, workflow demos |
| 1:10–1:30 | Organize assets into folders |

## Thursday — Editing · 2h 45m

| Block | Task |
|---|---|
| 0:00–0:30 | Assemble rough cut |
| 0:30–1:30 | Add screen recordings and core visuals |
| 1:30–2:00 | Add text overlays and callouts |
| 2:00–2:20 | Tighten pacing, remove dead space |
| 2:20–2:45 | Export and QC watch |

## Friday — Packaging + Shorts · 2h 00m

| Block | Task |
|---|---|
| 0:00–0:35 | Cut 2–3 Shorts |
| 0:35–1:00 | Captions, hook text, export |
| 1:00–1:25 | Design thumbnail |
| 1:25–1:40 | Write title options, choose final |
| 1:40–1:50 | Write description and pinned comment |
| 1:50–2:00 | Affiliate links, chapters, schedule uploads |

## Sunday — Review · 45m

| Block | Task |
|---|---|
| 0:00–0:20 | Check published performance |
| 0:20–0:35 | Log metrics in Notion |
| 0:35–0:45 | Write one lesson and one next-step action |

# Tier 2 — Aggressive (2 long-form + 7 Shorts)

**Total: ~18h 05m/week.** This is not a small step up from Tier 1 — it is close to double.
Do not commit to it on the assumption that the second video is cheaper than the first;
only planning and the weekly review are shared.

| Task | Tier 1 | Tier 2 | Why |
|---|---:|---:|---|
| Planning | 1h 15m | 1h 30m | Two topics, but one analytics pass |
| Scripting | 1h 30m | 3h 00m | Fully doubled |
| Recording | 1h 30m | 3h 00m | Fully doubled |
| Long-form editing | 2h 45m | 5h 30m | Fully doubled |
| Shorts editing | 1h 00m | 2h 20m | 7 Shorts at ~20m each |
| Packaging | 1h 00m | 2h 00m | Doubled: thumbnail, title, description, upload |
| Weekly review | 45m | 45m | Shared |
| **Total** | **9h 45m** | **18h 05m** | |

## Tier 2 weekly shape

| Day | Block | Time |
|---|---|---:|
| Monday | Plan both videos, queue 7 Shorts angles | 1h 30m |
| Tuesday | Script video A, script video B | 3h 00m |
| Wednesday | Record video A and video B | 3h 00m |
| Thursday | Edit video A | 2h 45m |
| Friday | Edit video B | 2h 45m |
| Saturday | Cut 7 Shorts, package both videos, schedule everything | 4h 20m |
| Sunday | Weekly review | 45m |

If Saturday consistently overruns, that is the signal to hire an editor or drop back to
Tier 1 — not to skip the review block. The review block is the only part of the week
that makes the next week better.

---

## Format discipline that makes either tier fit

- **Three formats only:** roundups, comparisons, tutorials. Every new format costs a week
  of learning curve.
- **6–9 minutes** for long-form. Longer videos do not fit the editing block.
- **One thumbnail style.** Redesigning from scratch weekly is the single biggest hidden
  time sink, and it also destroys your packaging comparisons.
- **One script structure.** Familiar structure speeds up both writing and editing.
- **Shorts come from the long-form only,** unless something is trending hard. Original
  Shorts are a separate production line and are not budgeted here.
- **Track five metrics:** CTR, retention at 30s, average view duration, affiliate clicks,
  comments. Everything else is curiosity, not decision-making.
